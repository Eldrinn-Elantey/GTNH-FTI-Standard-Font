# GTNH-FTI-Standard-Font

> [!IMPORTANT]
> [Angelica](https://github.com/GTNewHorizons/Angelica) [2.2.30](https://github.com/GTNewHorizons/Angelica/releases/tag/2.2.30) and newer bundle modern Minecraft's font sheets and draw text with them by default, so you do not need this resourcepack there. It still applies if you turn off `enableModernFont` or tick Force Unicode Font in the language menu.
